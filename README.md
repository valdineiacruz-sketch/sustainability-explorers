# Projeto Integrador: Inovação

Quero que faça um site para o produto final da disciplina de resolução de problemas, esse site engloba três disciplina: Matemática (resolução de problemas), química e tecnociência, biologia ( sustentabilidade em ação), o objetivo dele e mostrar 2 projetos desenvolvidos, um terrário e um filtro de água, quero que use as fotos e descreva o processo de construção de cada e sua importância, coloque no rodape a turma 1º ano A Projeto Integrador - Colégio Estadual do Campo de Alto São Joao EFM/TI
